# 📊 HR Workforce Analytics Dashboard — Power BI Project

## 📌 Project Summary
This project is an end-to-end **HR analytics dashboard solution built using Microsoft Power BI**, designed to transform raw employee attendance data into actionable workforce insights. It helps HR teams and leadership monitor attendance behavior, remote work trends, and employee leave patterns to support data-driven workforce planning.

---

## ❗ Problem Statement
HR teams often struggle with:
- Manual and error-prone analysis of large attendance datasets
- Lack of visibility into absenteeism and WFH trends
- Difficulty identifying seasonal or behavioral attendance patterns

This project solves these challenges by automating analysis through an interactive Power BI dashboard.

---

## 🎯 Objective
- Convert raw attendance spreadsheets into structured insights
- Track employee presence, WFH, and leave trends
- Identify workforce behavior patterns across time
- Enable HR decision-making through interactive visual analytics

---

## 🚀 Key Features
- Interactive Power BI dashboard with slicers and filters
- Monthly attendance, WFH, and sick leave trend analysis
- Employee-level drill-down view
- Day-of-week behavioral analysis
- KPI tracking for presence %, WFH %, and leave distribution
- Dynamic time-based filtering (month/quarter/year)

---

## 🧰 Tech Stack
- **Microsoft Power BI Desktop**
- **Power Query (M Language)** for data transformation
- **DAX (Data Analysis Expressions)** for KPIs and measures
- **Microsoft Excel** (source dataset)

---

## 📁 Dataset Source
- Attendance dataset (FY 2022–2023)
- Format: Excel (.xlsx) with monthly sheets
- Includes:
  - Employee ID
  - Date
  - Attendance Status (Present / WFH / Sick Leave / Paid Leave / Holiday)
- Data is anonymized to ensure privacy compliance

---

## ⚙️ Workflow / Process

### 1. Data Collection
- Imported multi-sheet Excel attendance data (2022–2023)

### 2. Data Cleaning & Transformation
- Handled inconsistent attendance labels
- Standardized date formats
- Merged monthly sheets into a unified dataset using Power Query

### 3. Data Modeling
- Built relationships and structured data model in Power BI
- Created calculated columns for attendance categories

### 4. KPI Development (DAX)
- Presence %
- WFH %
- Sick Leave %
- Paid Leave %
- Monthly trend metrics

### 5. Dashboard Development
- Built interactive visuals with filters and slicers
- Designed drill-down employee analysis view
- Created trend analysis charts for HR insights

---

## 📈 Key Insights
- 📊 Overall presence remained **~90%+**, indicating strong workforce attendance
- 🏠 WFH usage peaked on **Mondays and Fridays**, showing hybrid work preference
- 🤒 Sick leave spikes observed during **winter months**, indicating seasonal health impact
- 📉 WFH stabilized post-pandemic, showing consistent hybrid adoption
- 📅 Mid-week (Tue–Thu) showed highest in-office presence
